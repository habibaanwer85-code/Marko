# Marko AI — نسخة جاهزة للنشر

## اللي جوه المشروع

- `index.html` — واجهة ماركو الكاملة (شاشة تسجيل/دخول + شات + رفع صور + جداول منسقة).
- `api/chat.js` — سيرفر مصغّر (Vercel Serverless Function) بيستقبل الرسالة من الواجهة، يبعتها لـ **Anthropic Claude API** (موديل `claude-sonnet-4-6`، من أقوى الموديلات المتاحة دلوقتي لمهام التسويق والتحليل والكتابة)، ويرجع الرد. ده اللي بيخلي مفتاح الـ API مخبى وآمن.
- `package.json` — ملف بسيط للمشروع.

## ليه محتاجين سيرفر أصلاً؟

مفتاح Anthropic API (API Key) لازم يفضل سري. لو الواجهة نادت على `api.anthropic.com` مباشرة من المتصفح، أي حد يقدر يفتح "Inspect" ويسرق المفتاح. عشان كده الواجهة بتنادي على `/api/chat` بتاعتك انت، وهو اللي بينادي على Anthropic بالمفتاح من غير ما يظهر لحد.

## خطوات النشر (Vercel — مجاني وسهل)

1. اعملي حساب على [vercel.com](https://vercel.com) (تقدري تسجلي بحساب GitHub).
2. ارفعي المجلد ده على GitHub كـ repository جديد (أو اسحبيه مباشرة على Vercel لو مفيش GitHub).
3. من لوحة Vercel: **Add New → Project** واختاري الـ repo.
4. قبل ما تعملي Deploy، روحي على **Settings → Environment Variables** وضيفي:
   - **Name:** `ANTHROPIC_API_KEY`
   - **Value:** مفتاح الـ API بتاعك من [console.anthropic.com](https://console.anthropic.com)
5. اضغطي **Deploy**. بعد دقيقة أو اتنين هيديكي رابط زي `marko-ai.vercel.app` — ده رابط ماركو الرسمي، شغال على الموبايل والديسكتوب، ورفع الصور هيشتغل عادي.

## شاشة الدخول (Sign up / Login)

قبل ما أي حد يدخل الشات، بيشوف شاشة "حساب جديد / تسجيل دخول" بتاخد الاسم والإيميل والباسورد.

⚠️ **مهم تعرفيه:** ده تسجيل بسيط جوه المتصفح بس (localStorage) — مفيش قاعدة بيانات حقيقية على سيرفر، ومفيش تشفير للباسورد، ومفيش مزامنة بين الأجهزة. يعني:
- كل حساب بيفضل محفوظ على المتصفح/الجهاز اللي اتسجل بيه بس.
- لو المستخدم مسح بيانات المتصفح أو استخدم جهاز تاني، هيحتاج يعمل حساب من جديد.
- ده مناسب كواجهة أنيقة تفتح تجربة "شخصية" للمستخدم، لكنه مش نظام حسابات حقيقي بمعنى أمان أو استمرارية عبر الأجهزة.

لو عايزة حسابات حقيقية (تفتحي من أي جهاز، باسورد مشفّر، إدارة مستخدمين)، محتاجة قاعدة بيانات وخدمة auth حقيقية (زي Supabase أو Firebase Auth) — ده تطوير إضافي منفصل لو حبيتِ نعمله بعدين.

## اختبار محلي (اختياري، لو عندك Node.js)

```bash
npm install -g vercel
vercel dev
```

هيفتحلك نسخة محلية على `localhost:3000` بنفس سلوك النشر الحقيقي.

## تعديل شخصية ماركو لاحقًا

كل تعليمات وقواعد ماركو (القاعدة الصفرية، أسلوب الرد، الذكاء الإعلاني، محرك الرغبة، مكتبة المبادئ الإبداعية...) موجودة في متغير `BASE_SYSTEM_PROMPT` جوه `index.html`. تقدري تعدلي فيه في أي وقت وترفعي التحديث على GitHub، وVercel هيحدث الموقع تلقائيًا.
