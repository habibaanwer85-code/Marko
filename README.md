# Marko AI — نسخة جاهزة للنشر

## اللي جوه المشروع

- `index.html` — واجهة ماركو الكاملة (شاشة تسجيل/دخول + شات + رفع صور + جداول منسقة).
- `api/chat.js` — سيرفر مصغّر (Vercel Serverless Function) بيستقبل الرسالة من الواجهة ويبعتها للذكاء الاصطناعي، ويرجع الرد. ده اللي بيخلي مفاتيح الـ API مخبية وآمنة.
- `package.json` — ملف بسيط للمشروع.

## إزاي الذكاء الاصطناعي شغال دلوقتي: Groq أولًا + Gemini كـ Fallback

`api/chat.js` بيجرب **Groq** الأول (موديل `meta-llama/llama-4-maverick-17b-128e-instruct` — سريع جدًا وبيدعم الصور). لو Groq فشل لأي سبب (المفتاح مش موجود، مشكلة شبكة، أو رد خطأ من Groq)، الكود يرجع تلقائيًا يجرب **Gemini** (موديل `gemini-3.6-flash`) كبديل، من غير ما تحسي بأي فرق في الواجهة.

يعني محتاجة تضيفي **الاتنين** كمفاتيح في Vercel عشان الـ Fallback يشتغل صح.

## ليه محتاجين سيرفر أصلاً؟

مفاتيح الـ API لازم تفضل سرية. لو الواجهة نادت على Groq أو Gemini مباشرة من المتصفح، أي حد يقدر يفتح "Inspect" ويسرق المفتاح. عشان كده الواجهة بتنادي على `/api/chat` بتاعتك انت، وهو اللي بينادي على الخدمتين بالمفاتيح من غير ما تظهر لحد.

## خطوات النشر (Vercel — مجاني وسهل)

1. اعملي حساب على [vercel.com](https://vercel.com) (تقدري تسجلي بحساب GitHub).
2. ارفعي المجلد ده على GitHub كـ repository جديد (أو اسحبيه مباشرة على Vercel لو مفيش GitHub).
3. من لوحة Vercel: **Add New → Project** واختاري الـ repo.
4. قبل ما تعملي Deploy، روحي على **Settings → Environment Variables** وضيفي المتغيرين دول الاتنين:
   - **Name:** `GROQ_API_KEY` — **Value:** مفتاحك من [console.groq.com](https://console.groq.com)
   - **Name:** `GEMINI_API_KEY` — **Value:** مفتاحك من [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey)
5. اضغطي **Deploy**. بعد دقيقة أو اتنين هيديكي رابط زي `marko-ai.vercel.app` — ده رابط ماركو الرسمي، شغال على الموبايل والديسكتوب، ورفع الصور هيشتغل عادي.

## تأكدي إن الملف في المكان الصح

المسار لازم يكون بالظبط `api/chat.js` (فولدر اسمه `api` بحروف صغيرة، جواه ملف `chat.js`) في جذر الريبو. لو الملف في مكان تاني، Vercel مش هيتعرف عليه كـ Serverless Function، وهتظهرلك رسالة خطأ زي "The page could not be found" بدل رد ماركو.

## شاشة الدخول (Sign up / Login)

قبل ما أي حد يدخل الشات، بيشوف شاشة "حساب جديد / تسجيل دخول" بتاخد الاسم والإيميل والباسورد.

⚠️ **مهم تعرفيه:** ده تسجيل بسيط جوه المتصفح بس (localStorage) — مفيش قاعدة بيانات حقيقية على سيرفر، ومفيش تشفير للباسورد، ومفيش مزامنة بين الأجهزة. كل حساب بيفضل محفوظ على المتصفح/الجهاز اللي اتسجل بيه بس.

لو عايزة حسابات حقيقية (تفتحي من أي جهاز، باسورد مشفّر، إدارة مستخدمين)، محتاجة قاعدة بيانات وخدمة auth حقيقية (زي Supabase أو Firebase Auth).

## اختبار محلي (اختياري، لو عندك Node.js)

```bash
npm install -g vercel
vercel dev
```

هيفتحلك نسخة محلية على `localhost:3000` بنفس سلوك النشر الحقيقي.

## تعديل شخصية ماركو لاحقًا

كل تعليمات وقواعد ماركو موجودة في متغير `BASE_SYSTEM_PROMPT` جوه `index.html`. تقدري تعدلي فيه في أي وقت وترفعي التحديث على GitHub، وVercel هيحدث الموقع تلقائيًا.
