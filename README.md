# Marko AI — نسخة جاهزة للنشر

## اللي جوه المشروع

- `index.html` — واجهة ماركو الكاملة (شاشة ترحيب + شات + رفع صور + جداول منسقة).
- `api/chat.js` — سيرفر مصغّر (Vercel Serverless Function) بيستقبل الرسالة من الواجهة، يبعتها لـ Anthropic API، ويرجع الرد. ده اللي بيخلي مفتاح الـ API مخبى وآمن، وبيحل مشكلة رفع الصور لأنه هيشتغل في متصفح حقيقي مش معاينة محمية.
- `package.json` — ملف بسيط للمشروع.

## ليه محتاجين سيرفر أصلاً؟

مفتاح Anthropic API (API Key) لازم يفضل سري. لو الواجهة نادت على `api.anthropic.com` مباشرة من المتصفح، أي حد يقدر يفتح "Inspect" ويسرق المفتاح. عشان كده الواجهة بتنادي على `/api/chat` بتاعتك انت، وهو اللي بينادي على Anthropic بالمفتاح من غير ما يظهر لحد.

## خطوات النشر (Vercel — مجاني وسهل)

1. اعملي حساب على [vercel.com](https://vercel.com) (تقدري تسجلي بحساب GitHub).
2. ارفعي المجلد ده على GitHub كـ repository جديد (أو اسحبيه مباشرة على Vercel لو مفيش GitHub).
3. من لوحة Vercel: **Add New → Project** واختاري الـ repo.
4. قبل ما تعملي Deploy، روحي على **Settings → Environment Variables** وضيفي:
   - **Name:** `ANTHROPIC_API_KEY`
   - **Value:** مفتاح الـ API بتاعك من [console.anthropic.com](https://console.anthropic.com)
5. اضغطي **Deploy**. بعد دقيقة أو اتنين هيديكي رابط زي `marko-ai.vercel.app` — ده رابط ماركو الرسمي، شغال على الموبايل والديسكتوب، ورفع الصور هيشتغل عادي.

## اختبار محلي (اختياري، لو عندك Node.js)

```bash
npm install -g vercel
vercel dev
```

هيفتحلك نسخة محلية على `localhost:3000` بنفس سلوك النشر الحقيقي.

## تعديل شخصية ماركو لاحقًا

كل تعليمات وقواعد ماركو (القاعدة الصفرية، المراحل الأربعة، الأسلوب...) موجودة في متغير `SYSTEM_PROMPT` جوه `index.html`. تقدري تعدلي فيه في أي وقت وترفعي التحديث على GitHub، وVercel هيحدث الموقع تلقائيًا.
